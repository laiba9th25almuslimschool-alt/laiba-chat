Python mein bubble sort kaise likhte hain? Ek example bhi do.
Zaroor! Yeh raha bubble sort ka ek simple example:

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

Is mein adjacent elements compare hote hain aur agar galat order mein hon to swap hote hain. Time complexity O(n²) hai.

Kya yeh O(n log n) se better hai?
Nahi, bilkul nahi! O(n²) aslaan O(n log n) se kaafi slow hai.

Comparison:
• Bubble Sort → O(n²) — sirf chhoti lists ke liye theek hai
• Merge Sort → O(n log n) — large data ke liye best
• Quick Sort → O(n log n) average — practical use mein fast

Isliye production code mein bubble sort use nahi karte. Yeh sirf seekhne ke liye useful hai.
